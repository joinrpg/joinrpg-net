# Как сделать регулярные джобы

Есть класс `MidnightJobBackgroundService<TJob>` на основе `BackgroundService`.
Его нужно зарегать для каждой джобы (см `DailyJobRegistration`

Он при старте спит до примерно полуночи (плюс случайное количество 5–10 секунд, чтобы не было эффекта нагрузки в ровный час). Потом он по очереди пытается запустить свой `IDailyJob`
Запуск джобы это `INSERT` в табличку `DailyJobRuns text Name, text RunId, enum Status` где `RunId` = 2024-05-05
- У этой таблички уникальный индекс на (Name, RunId)
- Если вставка завершилась неудачей, то джоба уже запущена на другом экземпляре, пытайся запустить следующий тип джобы.
- Если джоба отработала успешно меняем статус на успешный.
- Если джоба упала, меняем статус на ERROR
Все действия пишем в лог.

Таким образом:
- Джоба запускается at most once
- Разные джобы могут быть запущены в параллель на разных экземплярах контейнера или одном
- Джоба может навсегда зависнуть в каком-то статусе (например, быть запущена и не завершится). В этом случае она будет запущена на другой день
- Ответственность джобы идемпотентность (т.е. если она вчера не отработала, должна сделать сегодня за вчера)
- Можно потом добавить механизм ручного перезапуска
- Если контейнер будет штатно выключаться во время работы джобы, у нее 30 секунд, чтобы доделать свою работу

## Как выключить джобу конфигом

Настройка `DailyJobs:Disabled` (класс `DailyJobsOptions` в `JoinRpg.Portal`) — список выключенных джоб.
Имя — короткое (`AdvertisementJob`) или полное (`JoinRpg.Services.Advertisement.AdvertisementJob`) имя класса, без учёта регистра.
По умолчанию список пуст — работают все джобы.

```json
"DailyJobs": {
  "Disabled": [ "ProjectPerformCloseJob", "AdvertisementJob", "UpdatePaymentStatusJob" ]
}
```

Через переменные окружения (так на проде):

```
DailyJobs__Disabled__0=ProjectPerformCloseJob
DailyJobs__Disabled__1=AdvertisementJob
DailyJobs__Disabled__2=UpdatePaymentStatusJob
```

Что происходит с выключенной джобой:
- В плановое время `MidnightJobBackgroundService` её не запускает и **не пишет** строку в `DailyJobRuns`, в лог уходит Warning «disabled by configuration».
- На `/Admin/Jobs` у неё метка «Выключена в конфигурации», кнопка запуска неактивна, POST тоже отклоняется.
- При старте в лог пишется Warning со списком выключенных джоб; неизвестное имя в списке — тоже Warning с перечнем известных джоб (сайт не падает).

Настройка читается на каждом плановом запуске (`IOptionsMonitor`). Если источник конфига перезагружаемый
(`appsettings*.json`), включение и выключение работают без рестарта. Переменные окружения читаются только при старте — после их смены нужен рестарт пода.

После включения джоба отработает на ближайшем плановом запуске (полночь UTC плюс `JobDelay`), за пропущенные дни — согласно своей идемпотентности.
Если плановое время сегодня ещё не наступило и сервис его ждёт, джоба отработает уже сегодня. Немедленно запустить можно вручную с `/Admin/Jobs`.

Джобы регистрируются только в `JoinRpg.Portal` (`IJoinServiceCollection.AddDailyJob`), в IdPortal их нет.
